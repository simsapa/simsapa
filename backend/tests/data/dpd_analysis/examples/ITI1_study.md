# Analysis of: ITI1

yena lobhena luddhāse,
sattā gacchan'ti duggatiṃ,
taṃ lobhaṃ samma'd'aññāya,
pajahanti vipassino,
pahāya na pun'āyanti,
imaṃ lokaṃ kudācanan'ti.

### English Translation

**Translation:** Beings who are greedy, because of that greed, go to a bad destination; the insightful ones, having completely understood that greed, abandon it; having abandoned it, they never return to this world.

**Literal Translation:** by which greed greedy beings go to bad destination; that greed having perfectly known abandon the insightful ones; having abandoned not they return this world ever.

### Variants

gacchan'ti//gacchanti
