# Analysis of: DHP23

te jhāyino sātatikā,
niccaṃ daḷhaparakkamā,
phusanti dhīrā nibbānaṃ,
yogakkhemaṃ anuttaraṃ.

### English Translation

**Translation:** Those wise ones, meditative, persevering, ever steadfast in their effort, attain Nibbāna, the unsurpassed release from bondage.

**Literal Translation:** Those meditators, persevering, constantly of firm effort, the wise ones touch Nibbāna, the unsurpassed security from bondage.
